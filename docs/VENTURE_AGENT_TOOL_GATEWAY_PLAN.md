# Future Venture Agent Tool-Gateway Plan
**Status: PROPOSED / NOT EXPOSED · 2026-11-05**

Canonical cross-repo plan: [Arche Coda Autonomous Venture Machine Master Plan](https://github.com/idotamdot/arche-coda/blob/main/AUTONOMOUS-VENTURE-MACHINE-MASTER-PLAN.md).
Trust policy owner: [Symbiont Venture Agent Authority Plan](https://github.com/idotamdot/Symbiont-Protocol/blob/main/VENTURE-AGENT-AUTHORITY-PLAN.md).

Arche MCP remains an **interoperability gateway**; it is not the AI agent runtime, organizational memory store, project database, financial account system, investment market, or authorization authority.

## Before adding venture tools
- [ ] Verify the present read-only registry and existing gateway authentication in deployed behavior; provider domain attachment is insufficient.
- [ ] Define versioned per-service contracts with least-privilege principal, tenant, scope, consent, token expiry, spend ceilings and requested action purpose.
- [ ] Require Symbiont service-side authorization and Arche Coda governing policy references before any write tool; model prompts never grant themselves scopes.
- [ ] Ensure each venture's private records remain in the venture's owning service with independent authorization; listing a service never implies data permission.
- [ ] Specify tool invocation, idempotency key, external action receipt, error state, rollback and separate verification record.
- [ ] Add read-only evidence access for Venture Agent Runtime after security and purpose review.
- [ ] Introduce carefully scoped write methods only after policy, qualified legal/operational approval, audit, revocation, and tests for malicious retrieved content.
- [ ] Keep sensitive legal signatures, securities activities, equity issuance and unbounded bank transfers outside automated tools by default.
- [ ] Test tenant isolation, provider failure, replay, permission revocation, quota exhaustion and cross-venture prompt injection.

No live tools, secrets, permission grants, investor matching or production actions are introduced by this plan.
